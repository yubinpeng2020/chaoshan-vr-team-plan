第十届"挑战杯"汕头职业技术学院学生课外学术科技作品竞赛 · 哲学社会科学类社会调查报告

- 题目：《云端有座潮汕，为什么没人走进去？——潮汕文化 VR／数字孪生类线上资源的可及性测评与受众使用意愿调查》
- 周期：2026-11-26 — 12-10（15 天）
- 内容：10 个人的岗位、要交的材料、建议操作路径、预计用时、关键日期

## 在线查看

启用 GitHub Pages 后地址为：

`https://yubinpeng2020.github.io/chaoshan-vr-team-plan/`

开启方式：仓库 **Settings → Pages → Build and deployment → Source 选 "Deploy from a branch" → Branch 选 `master`、目录选 `/ (root)` → Save**，等 1 分钟后刷新页面。

## 本地查看

直接双击 `index.html` 即可，无需服务器、无外部依赖（字体用系统字体，不联网也能正常显示）。

```

files/受众问卷_16题.html           问卷网页版，可直接照着建卷
```

## 适配

- 导航：全部 15 个标签一律换行显示，不做横向滚动（桌面两行、手机四行、320px 宽五行）
- 桌面端：三栏卡片网格，最大宽度 1060px 居中
- 手机端：单栏；材料表格自动转成"标签 + 值"的卡片，不出现横向滚动
- 已按 1440 / 1280 / 390 / 360 / 320 五种宽度验证：`scrollWidth === innerWidth`，无横向溢出，导航无截断
- 支持打印（A4 直接打印，导航与悬浮按钮自动隐藏）

## 修改方式

页面是单文件纯 HTML+CSS，改文字直接编辑 `index.html`，提交推送后 Pages 会自动更新。
